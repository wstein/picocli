io.github.wstein:picocli

This is a small self-hosted flat Maven repository for wstein/picocli, a personal fork of remkop/picocli used to prototype additions (e.g. fish shell completion) before/if they get contributed upstream.

It is not affiliated with the official info.picocli:picocli releases on Maven Central.

Usage

repositories {
    maven { url 'https://wstein.github.io/picocli/maven' }
}
dependencies {
    implementation 'io.github.wstein:picocli:<version>'
}
